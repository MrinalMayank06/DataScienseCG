# Python Lab Assignment Set (IPYNB Version)

This package contains 10 lab assignments in Jupyter Notebook (`.ipynb`) format.

## What is included
- Separate folder for each lab
- Executed notebooks with outputs visible below code cells
- Sample `.txt` / `.csv` files generated during notebook execution
- Runnable structure for academic submission and practice

## Labs
1. Python Fundamentals + File Handling
2. Data Types + Control Flow
3. Functions + Recursion
4. Regex + File Processing
5. Exception Handling
6. OOP + Inheritance
7. Decorators + Generators
8. Multithreading
9. NumPy + Pandas
10. Mini Project - Student Management System

## How to run
Open any notebook in Jupyter Notebook, JupyterLab, or VS Code and run cells if you want to regenerate outputs.
