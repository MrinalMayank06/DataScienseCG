# Student Success and Career Path Prediction

This project analyzes student academic performance data to predict
success outcomes and recommend academic interventions.

The system combines regression, classification, and clustering
techniques to understand student learning patterns.

------------------------------------------------------------------------

# Project Objectives

The university wants to analyze student performance to:

Predict final exam scores

Identify students who are at risk

Group students with similar study behaviors

Provide academic recommendations

------------------------------------------------------------------------

# Machine Learning Tasks

Regression

Predict final exam score using Linear Regression.

Classification

Classify students as At Risk or On Track using:

Logistic Regression

K-Nearest Neighbors

Decision Tree

Clustering

Group students into learning behavior clusters using K-Means.

------------------------------------------------------------------------

Python

# Workflow

Load student dataset

------------------------------------------------------------------------

# How to Run the Project

Step 1: Install required libraries

pip install pandas numpy matplotlib seaborn scikit-learn

Step 2: Ensure the dataset CSV file is available.

Step 3: Run the script

python StudentSuccessCareer_Path_Prediction.py

The program will train models, generate visualizations, and produce
recommendations.

------------------------------------------------------------------------

# Model Evaluation

Regression performance is evaluated using:

R2 Score

Mean Squared Error

Classification models are evaluated using:

Accuracy

Confusion Matrix

Classification Report

------------------------------------------------------------------------

# Clustering

The project uses the K-Means clustering algorithm to group students
based on study habits.

The Elbow Method is used to determine the optimal number of clusters.

------------------------------------------------------------------------

# Recommendation System

The project generates personalized recommendations such as:

Extra tutoring

Regular monitoring

These recommendations help universities support students more
effectively.
